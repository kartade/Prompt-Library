# Prompt Library

Production: https://prompt-library-kartade.vercel.app

Static bilingual FR/EN prompt blog. Original user-provided layout and four prompts, with generated thumbnails next to each prompt, category filters, clipboard feedback, favicon and Open Graph / X metadata. English prompt texts are preserved verbatim; French translations are provided. Food and Product categories display an empty state until populated.

Deploy index.html, favicon.svg and the JPG assets with Vercel (Other, no build).
